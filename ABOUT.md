# About Convertly

**Convertly is a fast, private unit converter that works offline in your browser.**

The project provides a clean, responsive interface for 26 everyday and technical measurement categories. Users can search categories, convert values instantly, switch units, copy results, save favorite pairs, and return to recent conversions.

## Project goals

- Make common and technical unit conversions quick to find and easy to read.
- Run locally without installation, a user account, or a network connection.
- Keep saved activity in the user's browser on their own device.
- Use a small, dependency-free codebase that is straightforward to extend.

## Technology

The interface uses HTML, CSS, and JavaScript. Conversion factors are bundled with the project; `conversion_engine.py` also provides a reusable Python conversion engine. The Windows launcher opens the local browser interface.

## Repository description

Offline-first unit converter for 26 categories, with a responsive interface, local history, favorites, and no external dependencies.
